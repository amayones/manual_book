## Hasil akhir

Anda melihat ringkasan penjualan sesuai periode yang dipilih.

## Panduan

### 1. Kenali bagian Dashboard
![Tampilan awal Dashboard dengan kartu ringkasan](/assets/dashboard/step-1.png)
::: pin
1. [32,21] Kartu Total Penjualan
2. [61,16] Pemilih periode
:::
Kartu ringkasan (nomor 1) mengikuti periode yang dipilih (nomor 2).

::: note
Angka diperbarui maksimal satu menit setelah periode berubah.
:::

### 2. Pilih periode lain
![Panel filter periode terbuka dengan pilihan bulan](/assets/dashboard/step-2.png)
::: pin
1. [61,16] Pemilih periode
2. [61,38] Pilihan Bulan ini
:::
Klik **Pemilih periode** (nomor 1) lalu pilih **Bulan ini** (nomor 2).

::: tip
Pilih Minggu ini bila ingin melihat performa harian.
:::

## Troubleshooting

::: problem
**Masalah:** Kartu ringkasan masih menampilkan data bulan lalu.
**Penyebab:** Data di-cache selama satu menit.
**Solusi:** Tunggu satu menit atau ganti periode lalu kembali.
:::
