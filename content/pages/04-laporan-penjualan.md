## Sebelum mulai

Pastikan ada transaksi tersimpan pada periode yang ingin Anda lihat.

## Hasil akhir

Anda memperoleh ringkasan sesuai filter dan berkas ekspor bila diunduh.

## Panduan

### 1. Pilih periode laporan
![Halaman laporan dengan pemilih periode](/assets/laporan/step-1.png)
::: pin
1. [31,22] Pemilih periode
:::
Klik **Pemilih periode** (nomor 1) lalu pilih bulan atau rentang tanggal.

::: note
Periode bawaan adalah bulan berjalan.
:::

### 2. Saring status
![Panel filter terbuka dengan pilihan status Lunas](/assets/laporan/step-2.png)
::: pin
1. [54,22] Tombol Filter
2. [57,39] Pilihan Lunas
:::
Klik **Filter** (nomor 1), pilih **Lunas** (nomor 2), lalu tekan Terapkan.

### 3. Ekspor laporan
![Tombol Ekspor di kanan atas halaman laporan](/assets/laporan/step-3.png)
::: pin
1. [88,22] Tombol Ekspor
:::
Klik **Ekspor** (nomor 1) untuk mengunduh berkas CSV periode aktif.

::: tip
Ekspor ulang setelah mengganti filter bila perlu berkas per status.
:::

## Troubleshooting

::: problem
**Masalah:** Grafik kosong setelah periode dipilih.
**Penyebab:** Tidak ada transaksi pada periode itu.
**Solusi:** Lebarkan periode atau kembalikan filter ke Semua status.
:::

::: problem
**Masalah:** Berkas ekspor tidak terunduh.
**Penyebab:** Browser memblokir unduhan otomatis.
**Solusi:** Izinkan unduhan pada bilah alamat, lalu klik Ekspor lagi.
:::
