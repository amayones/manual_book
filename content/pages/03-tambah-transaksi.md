## Sebelum mulai

Siapkan nama pelanggan, nama produk, jumlah, dan harga satuan.

## Hasil akhir

Transaksi baru tersimpan sebagai baris teratas berstatus Baru.

## Panduan

### 1. Buka formulir baru
![Daftar transaksi dengan tombol Tambah](/assets/transaksi/step-1.png)
::: pin
1. [88,14] Tombol Tambah
:::
Klik **Tambah** (nomor 1) di kanan atas.

::: tip
Cari pelanggan lebih dulu bila ingin menghindari transaksi ganda.
:::

### 2. Isi data transaksi
![Formulir transaksi baru yang masih kosong](/assets/transaksi/step-2.png)
::: pin
1. [47,28] Kolom Pelanggan
2. [47,41] Kolom Produk
3. [34,53] Kolom Jumlah
:::
Isi **Pelanggan** (nomor 1), pilih **Produk** (nomor 2), isi **Jumlah** (nomor 3). Total dihitung otomatis.

::: warn
Periksa harga satuan sebelum menyimpan.
:::

::: note
Tombol Simpan aktif setelah semua kolom terisi.
:::

### 3. Simpan transaksi
![Formulir terisi dengan tombol Simpan ditekan](/assets/transaksi/step-3.png)
::: pin
1. [31,82] Tombol Simpan
:::
Periksa nama dan total, lalu klik **Simpan** (nomor 1).

::: warn
Jangan menutup halaman selama tombol Simpan masih berputar.
:::

### 4. Cek di daftar
![Daftar transaksi dengan baris baru di urutan teratas](/assets/transaksi/step-4.png)
::: pin
1. [59,35] Baris transaksi baru
:::
Baris teratas (nomor 1) berstatus Baru.

::: tip
Statusnya menjadi Lunas setelah pembayaran dicatat.
:::

## Troubleshooting

::: problem
**Masalah:** Tombol Simpan tidak bisa diklik.
**Penyebab:** Kolom harga masih kosong.
**Solusi:** Isi kolom harga, tombol Simpan akan aktif.
:::

::: problem
**Masalah:** Transaksi yang sama tercatat dua kali.
**Penyebab:** Tombol Simpan ditekan dua kali saat koneksi lambat.
**Solusi:** Hapus salah satu lewat menu titik tiga pada baris transaksi.
:::
